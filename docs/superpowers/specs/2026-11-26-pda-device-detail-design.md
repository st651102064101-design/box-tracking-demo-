# หน้าข้อมูลเครื่อง PDA

## ทำไม

กดการ์ด PDA บนหน้าภาพรวมตอนนี้ได้หน้า QR เชื่อมต่อเสมอ แม้เครื่องออนไลน์อยู่
ผู้ใช้ต้องการรู้ว่าเป็นเครื่องไหน ใครใช้อยู่ และสถานะเป็นอย่างไร

## เป้าหมาย / ไม่ทำ

- กดการ์ดแล้วเห็นข้อมูลของเครื่องนั้น อ่านเข้าใจในครั้งเดียว ใช้ได้บนจอแคบ
- เปิดหน้า QR ได้จากปุ่มในหน้าข้อมูล และ QR ต้องใช้เชื่อมต่อได้จริง
- ไม่ทำ: ประวัติการใช้เครื่อง, แบตเตอรี่, สั่งงานเครื่องจากเว็บ, เก็บสถานะลงฐานข้อมูล
  (รีสตาร์ตเซิร์ฟเวอร์แล้วรายชื่อเครื่องกลับมาเมื่อเครื่องส่งสถานะรอบถัดไป)

## ทางเลือก

| แบบ | ข้อดี | ข้อเสีย |
|---|---|---|
| ก. แก้แค่เซิร์ฟเวอร์และเว็บ | ไม่ต้องลงแอปใหม่ | ไม่รู้ว่าใครใช้ |
| **ข. แก้แอปด้วย (เลือก)** | รู้ชื่อคนใช้ | ต้อง build และลงแอปใหม่ |

ผู้ใช้เลือกแบบ ข. เมื่อ 2026-11-26

## หน้าจอ

```
┌ Zebra TC52                    ● Online ┐
│ ผู้ใช้งาน   ผู้ดูแลระบบ (Admin)          │
│ ประจำที่    คลัง 1 บางปู · ประตู 1       │
│ ติดต่อล่าสุด  8 วินาทีที่แล้ว             │
├ ข้อมูลเครื่อง ─────────────────────────┤
│ รุ่น TC52 · IP 192.168.3.115           │
│ บาร์โค้ด ✓   RFID ในตัว ✗              │
├────────────────────────────────────────┤
│ [เชื่อมต่อเครื่องใหม่ (QR)]      [ปิด]    │
└────────────────────────────────────────┘
```

- ไม่มีคนเข้างาน: ผู้ใช้งานแสดง "ยังไม่มีผู้เข้างาน"
- Offline: แสดงเวลาที่ติดต่อล่าสุด และข้อแนะนำ: เปิดแอปค้างไว้, อยู่ Wi-Fi เดียวกับเซิร์ฟเวอร์
- ยังไม่เคยมีเครื่องติดต่อ: กดการ์ดแล้วเปิดหน้า QR ตามเดิม
- ข้อมูลที่เครื่องไม่ได้ส่งมา แสดง "—"
- หน้าที่เปิดอยู่ปรับตามสถานะล่าสุด
- QR: ถ้าหน้าเว็บเปิดผ่าน `localhost` ให้กรอกที่อยู่ IP ของเครื่องเซิร์ฟเวอร์ก่อน จึงสร้าง QR
  (จำค่าที่กรอกไว้ในเบราว์เซอร์)

## ข้อมูลที่ส่ง

| ฝั่ง | การเปลี่ยน |
|---|---|
| แอป (branch `MOBILE_APP_DEMO`) | heartbeat เพิ่ม `employeeId`, `employeeName` ของคนที่เข้างานอยู่ และส่งทันทีเมื่อเข้างาน / ออกจากงาน |
| เซิร์ฟเวอร์ (`main`) | รับและส่งต่อ ชื่อคนใช้, รุ่น, IP, RFID ในตัว, Zebra SDK |
| เว็บ (`main`) | หน้าข้อมูลเครื่อง และแก้หน้า QR |

- แอปรุ่นเก่าที่ไม่ส่งชื่อ ยังใช้งานได้ตามเดิม
- ชื่อคนใช้เป็นค่าที่เครื่องรายงานเอง ใช้เพื่อแสดงผลเท่านั้น ไม่ใช้ตัดสินสิทธิ์
