# ใช้ PDA ได้ในระบบประตู (อนุมัติ 2026-11-27 "ทำเลย")

- ระบบ RFID Gate และระบบประตูทั้ง 3 แสดงอุปกรณ์ PDA บนหน้ารายงาน
- PDA ยิงรับ/ส่งได้ตามปกติ กติกาทิศประตูของเซิร์ฟเวอร์เหมือนเดิม
- ส่งออกจาก PDA: เลือกลูกค้าที่ตั้งไว้ที่ประตูให้ล่วงหน้า เปลี่ยนได้
- แถบความพร้อม: ระบบครบทุกฟีเจอร์เตือนเมื่อไม่มี/ออฟไลน์ ระบบอื่น PDA เป็นตัวเสริม ไม่เตือน

ค่าที่ผู้พัฒนาเลือกเอง (ผู้ใช้ไม่ได้ระบุ): PDA ใช้ได้ปกติแม้ในระบบอัตโนมัติ; ลูกค้าเลือกให้ล่วงหน้าแต่ต้องกดยืนยัน

ไม่ทำรอบนี้: ให้ PDA ตั้งประตูตามเว็บเอง (ผู้ใช้เลือกประตูบนเครื่องเหมือนเดิม)
