# ลูกค้าที่ตั้งไว้ที่ประตู: เวลานับถอยหลังและแบบถาวร (อนุมัติ 2026-11-27)

- เลือกระยะ 2 ชม. / 8 ชม. (ค่าเริ่ม) / ถาวร; ถาวรต้องกดยืนยัน
- หลังตั้ง: การ์ดสถานะ ลูกค้า เวลานับถอยหลัง แถบเวลา ตั้งเมื่อ/โดย ปุ่มต่อเวลา เปลี่ยนลูกค้า หยุดใช้
- เหลือไม่ถึง 15 นาที = เหลือง; หมดเวลา = ปุ่มใช้ลูกค้าเดิมอีกครั้ง; ถาวร = เหลืองตลอด บอกใช้มานานเท่าไร และขึ้นเตือนในแถบความพร้อม
- เวลาเก็บที่เซิร์ฟเวอร์ นับจากตอนตั้ง
- หน้าอื่นที่ซิงก์ข้อมูลประตูอัตโนมัติ ต้องไม่ลบหรือทับลูกค้าที่ตั้งจากหน้าประตู
- แก้บั๊ก: ป้ายรถคันแรกต้องไม่ถูกจำจนปฏิเสธคันถัดไป
- รายการ Excel ที่ป้ายตรงยังมาก่อน
