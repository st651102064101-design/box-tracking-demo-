# แถบความพร้อมของระบบ

## ทำไม
ผู้ใช้ต้องการรู้ในจอเดียวว่า ตอนนี้ทำงานได้หรือยัง และติดตรงไหน

## แบบ (อนุมัติ 2026-11-27)
บนสุดของหน้ารายงาน 3 กลุ่ม: อุปกรณ์, กล่อง, การส่งออก
เขียว = พร้อม, เหลือง = ต้องดู, แดง = ใช้งานไม่ได้, เทา = กำลังตรวจ (ห้ามขึ้นว่าพร้อมขณะยังไม่รู้)
ทุกอย่างพร้อม: ยุบเหลือแถบเดียว กดกางได้ กดรายการแล้วไปหน้าที่แก้ได้

| รายการ | เกณฑ์ |
|---|---|
| FX9600 | ไม่ผูกเลย หรือไม่ตอบสนอง = แดง |
| LPR (ระบบประตู 1–3 และครบทุกฟีเจอร์) | ไม่เคยส่งข้อมูล = เหลือง ระบบรู้แค่เวลาที่อ่านล่าสุด ไม่รู้ว่าออนไลน์ |
| PDA (ครบทุกฟีเจอร์) | ไม่มีหรือออฟไลน์ = เหลือง |
| กล่องพร้อมส่ง | 0 = แดง |
| ค้างคืน, สูญหาย, พัก/ชำรุด, ต้องตรวจ | มากกว่า 0 = เหลือง |
| ลูกค้า | ไม่มี = แดง |
| ขาออกอัตโนมัติ | ไม่มีรายการรอรถวันนี้และไม่ได้ตั้งลูกค้าที่ประตู = เหลือง |

## ทางเลือก
คำนวณบนหน้าเว็บจากข้อมูลที่มีอยู่ (เลือก) / ทำ API สรุปฝั่งเซิร์ฟเวอร์ (งานเพิ่มโดยยังไม่จำเป็น)

## ไม่ทำ
แจ้งเตือนนอกจอ, สถานะของเครื่องยิงที่ไม่ได้รายงานเข้าระบบ, แปลภาษาอังกฤษ
